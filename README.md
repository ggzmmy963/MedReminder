# 💊 药物提醒与健康管理系统 (MedReminder)

> **用物理锚定数字，让吃药不再靠猜。**
> 一个为记忆力减退人群（如老年人）及日常服药人群设计的极简用药管理工具。

## 💡 为什么做这个产品？
市面上大多数提醒 App 的逻辑是“到点响铃 + 点击已服”。但当记忆本身不可靠时，用户连“我是否点过按钮”都会忘记，从而极易导致重复服药（过量）或漏服。
本项目通过**“物理锚定”**的理念，解决最核心的痛点：**我到底吃没吃药？**

## ✨ 核心功能
- **📱 虚拟药板映射**：1:1 还原真实包装。支持自定义行/列、颜色，以及药片、口服液、冲剂形状。
- **🧩 半包/半片计算**：针对需要掰开服用的药物，提供“半格填充”的视觉反馈，数据精确到 0.5。
- **⏱️ 智能时间轴拦截**：抛弃死板的“一天一次”，采用时间戳计算服药间隔。未到时间点击会被强力拦截，防止补服过量。
- **👵 极简双模式**：一套数据，两套逻辑。长辈模式与普通模式无缝切换。
- **📄 一键就医摘要**：一键生成包含基础病、过敏史、当前用药清单的摘要卡片。

## 🛡️ 安全与隐私
- **数据本地化**：基于 LocalStorage 存储，默认保存在您的设备中，不上传云端。
- **零外部依赖**：单文件 HTML 架构，无外部 CDN 依赖。
- **合规边界**：本系统仅为记录辅助工具，**不提供任何医疗诊断**。
